## Skills da biblioteca

Use as skills selecionadas para este projeto nas tarefas que correspondem às suas descrições. Quando o usuário corrigir o resultado de uma skill usada, ou quando a própria verificação da skill demonstrar uma falha reproduzível, aplique o roteiro de aprendizado de `$projetar-skill`.

Prepare um caso sintético e registre-o na área local de feedback definida pelo projeto. Use a revisão da biblioteca instalada. Compartilhe o caso pelo fluxo de revisão do repositório após verificar que os exemplos podem ser divulgados.
